# Checkpoints

The main release is [massive-saes](https://huggingface.co/nathandelisle/massive-saes).

| Repository | Contents |
|---|---|
| [massive-saes](https://huggingface.co/nathandelisle/massive-saes) | Nine models, standard and bypass, five seeds; training means and PC1s. |
| [massive-saes-objectives](https://huggingface.co/nathandelisle/massive-saes-objectives) | Five-seed objective comparisons. |
| [massive-saes-layers](https://huggingface.co/nathandelisle/massive-saes-layers) | Five-seed additional-layer comparisons. |
| [massive-saes-extras](https://huggingface.co/nathandelisle/massive-saes-extras) | Magnitude penalties, Gated controls, matched coefficients, and original layer comparisons. |
| [massive-saes-archive](https://huggingface.co/nathandelisle/massive-saes-archive) | Earlier objectives, ten-seed GPT-2, magnitude sweeps, and Llama-70B. |
| [massive-saes-results](https://huggingface.co/datasets/nathandelisle/massive-saes-results) | Large measurement arrays and released-SAE statistics. |

`files.csv` lists checkpoint paths and SHA-256 hashes. `repositories.json` pins each repository revision. See [the loader example](../pc1_sae/README.md) to use an SAE.
